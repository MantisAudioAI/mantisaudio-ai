# Mantis Audio AI: Future Music Design

Mantis Audio AI is a development ecosystem dedicated to creating next-generation, hands-on, and interactive new age music tools. Instead of relying on passive, one-click song generators, this project builds tactical interfaces and systems that empower creators to actively sculpt soundscapes, textures, and atmospheric compositions.


## 🎛️ Core Focus

* **Interactive Tooling:** Building tangible, responsive audio components for real-time manipulation.

* **New Age Sonic Environments:** Designing expansive, ambient, and fluid generative sound engines.

* **Architectural Approach:** Emphasizing creative human-in-the-loop audio engineering over automated track generation.


## 🛠️ Tech Stack & Architecture

* Core Audio Engine: Web Audio API / C++
* AI Framework: PyTorch / ONNX Runtime
* Traditional Coding Tools & Languages: Python, C++/Java, HTML, and related web technologies
