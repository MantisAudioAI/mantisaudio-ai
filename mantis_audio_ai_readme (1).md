Mantis Audio AI: Future Music Design
====================================
Mantis Audio AI is a software development ecosystem and engineering project dedicated to building next-generation music production tools, hardware/software interfaces, and generative machine learning utilities. 

=====================================
🎛️ Core Focus
Interactive Tooling & DAWs: Building responsive audio components, custom beatmaking machines, drum machines, and samplers for real-time manipulation.

Generative Music & Vocal Tools: Designing machine learning pipelines and custom AI models tailored for music production and vocal synthesis.

Architectural Approach: Emphasizing creative human-in-the-loop developer tools, custom DSP, and low-latency audio control over automated black-box track generation.

=====================================
🛠️ Tech Stack & Architecture
Core Audio Engine: Web Audio API, C++ / C, Low-level DSP

AI & ML Frameworks: PyTorch, ONNX Runtime, Custom ML models for audio/vocal processing

Traditional Coding Tools & Languages: Python, C++, Java, HTML, and modern web/system technologies
